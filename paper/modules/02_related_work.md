**EN**

Prior work therefore establishes task diversity, shared modeling, data-dependent performance, and candidate-sensitive evaluation. We connect these themes by tracing specialist-shared relationships over cumulative per-task supervision, using a sequential-baseline trajectory and alternative candidate protocols as complementary comparisons and boundaries. Supervision formulation specifies the prediction capability to which each conclusion applies.

**ZH**

已有研究已经建立任务多样性、共享建模、数据依赖表现和候选敏感评估等主题。本文通过累计每任务监督下的专家-共享关系将其连接起来，并以序列基线轨迹和不同候选协议提供互补比较与边界。监督形式则明确每项结论所对应的预测能力。

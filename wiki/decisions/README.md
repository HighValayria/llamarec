# Decisions

Store Architecture Decision Records (ADRs) here. ADRs explain important decisions and their rationale.

Use sequential names such as:

- `ADR-001-example-decision.md`
- `ADR-002-example-decision.md`

Accepted ADRs are usually `authority: normative`. If a later ADR reverses an earlier one, mark the old ADR `superseded` and link `superseded_by` to the replacement.
